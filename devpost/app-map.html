ProofTrail

An evidence-backed requirements & action checklist extractor with deterministic quote verification and ambiguity detection.

Generated for Build With AI: Basics hackathon • Offline-safe snapshot

System Overview

ProofTrail splits messy instructions into verifiable actions. The AI model extracts structured candidates, but deterministic code validates ground truth against the original source text before display.

Core Code Reference Route

1. Deterministic Verification Kernel

lib/verifyQuote.ts • Function: verifyQuote & normalizeText

Normalizes smart quotes, linebreaks, and repeated whitespace. Searches for normalized quotes in source text. Dispatches items into VERIFIED, AMBIGUOUS, or UNVERIFIED.

2. Structured AI Extraction & Demo Fallback

app/api/analyze/route.ts • Function: POST

Prompts Gemini 2.5 Flash using responseSchema for structured output. Automatically falls back to lib/sampleData.ts if no API key is configured so demos never break.

3. Bidirectional Quote Highlighting & Scroll

components/SourcePanel.tsx • Function: renderHighlightedContent

Wraps matched quotes in interactive <mark> elements with scroll anchor IDs. Clicking a checklist card highlights and scrolls to the exact quote in the source panel.

4. Task Progress & Persistence

app/page.tsx & components/ChecklistPanel.tsx

Calculates completion percentages, supports filter pills (Deliverables, Deadlines, Rules), and synchronizes state to localStorage under key prooftrail_session.

To Change This, Start Here

To add new ambiguity checks (e.g. currency / platform rules)

Open app/api/analyze/route.ts and update the SYSTEM_INSTRUCTION and ambiguityReason description in EXTRACTION_SCHEMA.

To change the sample brief text

Edit lib/sampleData.ts (update SAMPLE_BRIEF_TEXT and corresponding PRECOMPUTED_SAMPLE_ITEMS).

To adjust quote normalization logic

Open lib/verifyQuote.ts and test your changes with npm test against lib/__tests__/verifyQuote.test.ts.

💡 A Practice to Reuse: Deterministic Verification of LLM Claims

When asking AI models to extract evidence from documents, never rely on the model's self-assessment to verify its own accuracy. By pairing structured model extraction with a deterministic string-matching engine (as in lib/verifyQuote.ts), you eliminate hallucinations and protect users from false assumptions before displaying output.
